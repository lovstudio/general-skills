# Consulting-grade infographic standard

The phrase “consulting-grade” describes editorial discipline, not imitation of
or affiliation with a specific firm. A strong one-pager is an argument made
visible.

## 1. Start with the decision

Before writing a title, answer:

- Who will see this?
- What do they already know?
- What decision, belief, or next action should change?
- What is the one sentence they should repeat after seeing the page?

If the source contains several equally important stories, split the work into
separate infographics. Do not shrink everything until it fits.

## 2. Use answer-first architecture

The governing message is a conclusion, not a topic label.

| Weak topic title | Strong action title |
|---|---|
| AI and organizational change | AI shifts advantage from model access to organizational learning speed |
| 2026 market overview | Growth is concentrating in two segments while the core market plateaus |
| Product roadmap | Three capability gates must be cleared before enterprise scale |

The page should follow:

```text
Governing message
├── Supporting claim 1
│   └── Evidence / mechanism
├── Supporting claim 2
│   └── Evidence / mechanism
└── Supporting claim 3
    └── Implication / action
```

Use MECE as an editing test, not as a reason to force artificial symmetry.

## 3. Maintain an evidence ledger

For every number, quote, named entity, causal assertion, or ranking, record:

- exact source text;
- source location or URL when available;
- unit and time period;
- whether it is fact, estimate, assumption, or interpretation;
- any caveat needed for honest reading.

Rules:

- Never invent values to populate a chart.
- Do not convert qualitative language into percentages.
- Do not remove a denominator, time period, or unit.
- Do not imply causation from correlation.
- When evidence is incomplete, label it as an assumption or use a conceptual
  diagram instead of a quantitative chart.

## 4. Apply a strict copy budget

CJK characters and Latin words are both counted as one semantic unit for these
editorial limits.

| Element | Recommended | Hard ceiling |
|---|---:|---:|
| Governing title | 12–24 | 34 |
| Subtitle / deck | 20–48 | 70 |
| Key takeaway band | 20–55 | 85 |
| Primary module label | 2–10 | 16 |
| Primary module explanation | 10–32 | 48 |
| Chart annotation | 3–16 | 24 |
| Primary modules | 3–5 | 7 |
| Distinct accent colors | 1–2 | 3 |

The hard ceiling is not a target. If copy repeatedly hits the ceiling, the
message architecture is probably unresolved.

Edit in this order:

1. remove repetition;
2. replace sentences with precise labels;
3. move caveats into a source note;
4. split the infographic if the argument still does not fit;
5. reduce font size only as a last resort.

## 5. Build a hierarchy, not a collection

Use four visual levels:

1. Governing message.
2. Main visual argument.
3. Evidence and annotations.
4. Sources, caveats, and attribution.

At full-page view, levels 1 and 2 must dominate. Level 4 must remain readable at
100% scale without competing for attention.

Every object must have one job:

- establish context;
- encode evidence;
- connect claims;
- clarify a mechanism;
- direct attention;
- identify source or ownership.

Delete objects that merely “make the page feel designed”.

## 6. Use restrained visual language

Default professional rules:

- light neutral canvas, dark ink, one brand accent;
- one sans-serif family with 3–4 weights/sizes;
- consistent corner radius and line weight;
- deliberate whitespace around the main argument;
- direct labels instead of detached legends;
- flat or near-flat surfaces; no fake 3D;
- no emoji, sticker icons, neon glow, glassmorphism, random gradients,
  decorative blobs, or repeated sparkles;
- icons only when they reduce reading time, not as decoration.

Illustrations should be custom and rare. If a diagram can communicate the
concept, prefer the diagram.

## 7. Chart integrity

- Bars start at zero unless a clearly marked exception is necessary.
- Lines encode ordered or continuous progression, usually time.
- Area implies magnitude; do not use it for arbitrary categories.
- Pie/donut charts are limited to a small part-to-whole story, normally no more
  than five slices.
- Avoid dual axes and perspective effects.
- Sort categories when order is not meaningful.
- Put the unit beside the value or axis.
- Annotate the point that supports the governing message.
- Include source and period in the page footer.

## 8. Definition of done

The infographic passes only when:

- the action title is supported by the visible evidence;
- a reader can describe the argument after a five-second glance;
- there is one obvious reading path;
- all numbers and quotes map to the evidence ledger;
- the visual form matches the information relationship;
- no element is clipped, crowded, or too small at 100%;
- logo, source, and generation attribution are present;
- removing any remaining element would weaken meaning or trust.
